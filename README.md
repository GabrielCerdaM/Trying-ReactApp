# My Project

Este proyecto es una aplicación React con Vite y TypeScript.

## Estructura
- `src/` - Código fuente principal
- `public/` - Archivos públicos
- `components/` - Componentes reutilizables
- `private/` y `public/` - Rutas protegidas y públicas

## Instalación

1. Instala las dependencias:
   ```sh
   bun install
   ```
2. Inicia el servidor de desarrollo:
   ```sh
   bun run dev
   ```

## Uso
- Accede a `/login` para iniciar sesión.
- Navega por las rutas privadas tras autenticación.

## Tecnologías
- React
- Vite
- TypeScript
- Tailwind CSS
- React Hook Form
- Zod
